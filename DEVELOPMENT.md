# Development

Technical companion to the [README](README.md): toolchain, building for desktop and mobile, testing, and architecture pointers. The design document and milestone plan is `PLAN-chain-notes-app.md` in the parent `prime/` workspace; protocol invariants are frozen in `prime-chain-notes/CLAUDE.md` and honored here.

## Stack

Rust end-to-end with a **Slint** UI (pinned `=1.17.1`), one shared `app.slint` across macOS, iOS, and Android:

- **macOS**: femtovg renderer, nokhwa camera, rfd file dialogs, Keychain + LAContext (Touch ID).
- **iOS**: winit + Skia (Metal), AVFoundation camera via objc2, Keychain.
- **Android**: android-activity + Skia (GL-ES), JNI for Keystore/clipboard/intents, NDK camera. Packaged with cargo-apk.

Platform forks live in `src/platform.rs` (clipboard, open-url, file dialogs — file-only buttons are hidden on mobile behind the `desktop-platform` Slint property).

`app-core/` is the UI-free core (identity import/create, BIP-32/86 derivation, chain client, store, compose orchestration) — host-testable without any UI. `notes-core` comes from the Prime app repo as a **pinned git dependency** and is the only producer of on-chain bytes; extensions to it are strictly additive so existing callers stay byte-identical.

## Toolchain

All builds (host + mobile) use the **standalone rustup** stable (`~/.cargo/bin`, ≥ 1.92 — slint 1.17 requires it; the Foundation SDK Nix shell's pinned nightly is too old). The ssh git dependency on `notes-core` needs an ssh-agent with access to the repo.

```bash
export PATH="$HOME/.cargo/bin:$PATH"
cargo test -p app-core        # host test suite
cargo run                     # launch the Mac app
bash scripts/regtest-e2e.sh   # app↔Prime interop matrix vs real bitcoind
```

Mobile: `build_ios.bash` (Xcode project via `project.yml`) and `cargo apk build --lib --target aarch64-linux-android`. The Android build needs **`ANDROID_NDK_ROOT`** exported, pointing at your installed NDK (e.g. `~/Library/Android/sdk/ndk/<version>`), or `cargo apk` fails with `Error: Android NDK is not found`. See `CLAUDE.md` for the per-platform gotchas (iOS launch watchdog, Android NoActionBar theme, icon/glyph rules).

## Testing

- **Host**: `cargo test -p app-core` (identity/derivation/store/compose, incl. parity fixtures generated by real `prime-bip85` outputs) and notes-core's own suite in its repo.
- **Hermetic e2e**: `scripts/regtest-e2e.sh` reuses the Prime companion's `server.py --regtest` (manages its own throwaway bitcoind) and drives both cores — this app's CLI (`examples/cli.rs`) against the Prime's `notes_cli` — proving cross-app note interop on a real chain.
- **UI e2e** (in the workspace's `ui-automation/tests/`): `chain-notes-app.sh` (smoke: compose→sign→broadcast + sweep) and `chain-notes-app-matrix.sh` (imports, account picker, create-seed + quiz, directed private note decrypted by a CLI identity, contacts, coins/consolidate, activity) drive the real Mac window with scripted CGEvents taps; `chain-notes-watch-signer.sh` drives the whole watch-only matrix headlessly against a hardware-signer simulator.
- **Live**: verified on testnet4 — including a directed private note decrypted by prime-core and a watch-only sweep + RBF replacement signed by the hardware-signer simulator through mempool.space. Mainnet deliberately untested (testnet4 + regtest are the acceptance bar).

## Key storage spec

Original key material is stored verbatim in the platform keychain/keystore only (macOS/iOS Keychain, ThisDeviceOnly, no sync; Android Keystore) behind app-core's `SecretStore` trait. Reveal always re-authenticates; derived keys are recomputed on unlock, never persisted. Store files are per-identity (`store-<network>-<fp8>.json`); node/explorer choices are device-level (`config.json`, keyed by network). No secrets in logs; `zeroize` on secrets.

## Architecture pointers

```
app-core/               # UI-free core: cargo test -p app-core
src/main.rs             # screen callbacks + --spike modes
src/{camera,keychain,qr,platform}.rs   # platform glue
ui/app.slint            # design system + all screens
ui/icons/*.svg          # icon assets (SVG only — femtovg has no font fallback)
scripts/                # bundle-mac.sh, regtest-e2e.sh, gen-icon-assets.sh
```
